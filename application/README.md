This is a modern chat interface built with Next.js 13+, TypeScript, and TailwindCSS. The interface supports both text and image responses, similar to ChatGPT.

## Features

- Modern, responsive UI similar to ChatGPT
- Support for text messages
- Support for image responses with captions
- Real-time message updates
- TypeScript for type safety
- TailwindCSS for styling

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `src/app/` - Next.js 13 app directory
- `src/components/` - React components
- `src/types/` - TypeScript type definitions
- `public/` - Static files

## Technologies Used

- Next.js 13+
